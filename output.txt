============================================
ANALYSIS
============================================

Tree Height: 3 edges

Traversal Behaviour:
Level-order traversal visits nodes level by level.
A queue is used for traversal.

Time Complexity:
Tree Construction: O(n)
Level-order Traversal: O(n)
Height Calculation: O(n)
Linear Search: O(n)
Binary Search: O(log n)

Suitability:
The N-ary tree is suitable for organisational reporting
because it represents parent-child relationships clearly.
A sorted array is suitable for department searching
because Binary Search provides O(log n) time complexity.
